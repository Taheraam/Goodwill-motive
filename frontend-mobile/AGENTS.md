# Goodwill Motive — Mobile Frontend Agent

## Stack
- React Native with Expo (managed workflow)
- TypeScript
- StyleSheet (no Tailwind — use the provided design system)

## Design Tokens
- Primary: `#E85D04` (orange)
- Secondary: `#0077B6` (blue)
- Accent: `#00C49A` (teal)
- Background: `#FAFAF8`
- Surface: `#FFFFFF`

## Key Screens
- `App.tsx` — Home screen

## Run Commands
```bash
cd frontend-mobile
npx expo start        # start Expo
npx expo start --web  # web preview
npx expo start --android  # Android dev client
```
